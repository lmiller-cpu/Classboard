Connect Canvas

Canvas won't accept requests straight from a web page, so this connects through a small relay you run yourself. Setup is a one-time, five-minute job and stays free.

The address you normally log in at, with nothing after the domain.
In Canvas: Account → Settings → New Access Token. Copy it once; Canvas won't show it again.
One more thing: when you save, Chrome will ask whether this extension may read your Canvas site. Click Allow — nothing loads without it.
From the Cloudflare Worker you deploy — see the setup steps below.
How to set up the relay
  1. Sign in at dash.cloudflare.com and open Compute → Workers.
  2. Create a Worker, name it classboard-relay, deploy the starter.
  3. Click Edit code, delete everything, and paste in canvas-proxy.js from this folder.
  4. Change the ALLOWED_HOSTS line near the top to your Canvas domain, then Deploy.
  5. Copy the *.workers.dev address into the relay field above.

Connect Google Classroom

Classroom talks to the browser directly, but Google needs to know which app is asking. You create a free client ID once, under your own Google account.

not connected
Classroom is optional. Canvas works without it.
How to switch it on
  1. Open chrome://extensions and copy this extension's ID.
  2. At console.cloud.google.com, create a project and enable the Google Classroom API.
  3. Credentials → Create credentials → OAuth client ID → Chrome Extension. Paste the ID.
  4. Open manifest.json in this folder, put that client ID on the client_id line, save.
  5. Back on chrome://extensions, hit reload on the Classboard card, then click Sign in above.
How to get a client ID
  1. Go to console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable Google Classroom API.
  3. Under the OAuth consent screen, pick External, and add your own school email as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application.
  5. Add this page's address as an authorized JavaScript origin, then copy the client ID here.
If sign-in gets blocked: some schools stop students from connecting outside apps to their school Google account. That's an admin setting, and nothing here can work around it. Canvas will still work on its own.
