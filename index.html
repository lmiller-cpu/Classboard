Set aside about 15 minutes the first time. Canvas needs two things — a token, and a small free relay you deploy once. Classroom is optional and can wait.

1 · Canvas

Canvas won't answer a web page directly, so this needs a token to prove it's you, and a relay to carry the request. Both are free and both are one-time.

Log into Canvas in another tab and copy what's in the address bar — the whole thing is fine, extra bits get trimmed. If your school uses a plain .instructure.com address you can type just the first word.
Open my Canvas token page ↗
On that page, scroll to Approved Integrations → + New Access Token. Purpose: anything. Leave the expiry blank so it doesn't stop working. Then Generate Token and copy it immediately — Canvas shows it once and never again.
One more thing: when you save, Chrome asks whether this extension may read your Canvas site. Click Allow — nothing loads without it.
You get this after the steps below. Nothing loads until it's filled in.
Never set up the relay? Full steps here
  1. Download canvas-proxy.js. Open a new browser tab, press Ctrl+O, choose the file — it opens as plain text. Press Ctrl+A then Ctrl+C to copy all of it.
  2. Go to dash.cloudflare.com and sign up. It's free and asks for no card.
  3. Left sidebar → Workers & Pages → Create application → Start with Hello World! → Get started.
  4. Name it classboard-relay → Deploy. First time only, Cloudflare asks you to pick a subdomain; anything is fine.
  5. Continue to project → Edit code.
  6. Click in the editor, Ctrl+A, Delete, then Ctrl+V to paste the relay code in.
  7. Near the top, swap yourschool.instructure.com for your real Canvas domain. Keep the quotes and the comma.
  8. Deploy. Copy the *.workers.dev address from the Worker's page into the box above.

2 · Google Classroom optional

Classroom needs some way to prove it's you. Three routes below — try the first, which works from a school account and needs no Google Cloud project. Skip this whole panel if you only use Canvas.

1 · Classroom feed full grades · no project
A short script runs inside your own Google account, reads Classroom, and passes the answer here. Google authorises it as you, so no project, client ID, or consent screen is involved anywhere.
Never set up the feed? Full steps here
  1. Open script.google.com/create signed in with your school account.
  2. Delete the sample code and paste in all of classroom-feed.gs.
  3. On line 15 you'll see const SECRET = 'CHANGE-ME';. Replace CHANGE-ME with a long phrase of your own — a few unrelated words. Keep the quotes. Write the phrase down.
  4. Press Ctrl+S to save.
  5. Left sidebar → Project Settings → tick Show "appsscript.json" manifest file in editor.
  6. Back in Editor, click appsscript.json, select all, and replace it with the contents of the appsscript.json file. Save. Skipping this causes a permissions error later.
  7. In the toolbar above the code there's a dropdown showing a function name. Choose testFeed, then click Run.
  8. Approve the permissions. "Google hasn't verified this app" is expected for your own script — Advanced → Go to…. The log at the bottom should list your classes.
  9. Deploy → New deployment → gear icon → Web app. Execute as Me, Who has access Anyone → Deploy.
  10. Copy the Web app URL ending in /exec into the field above, and your phrase into the key field.

Changed the script later? It won't take effect until you go Deploy → Manage deployments → pencil → Version: New version → Deploy.

Anyone holding that link can call it, so the key is what protects your grades. Make it long, don't post the link anywhere, and change SECRET to revoke it.
2 · Class calendar links — due dates only, no grades
Every class also has a calendar in Google Calendar. Open calendar.google.com, hover a class under My calendars, three dots → Settings and sharing → scroll to Integrate calendar → copy Secret address in iCal format. Treat these like passwords.
